Host artifacts live on Nexus at `repo.yuri.capital`. Pick **one** Maven
repository: releases for numbered versions, or snapshots for `*-SNAPSHOT*`.
Do not add both — Gradle will mix channels.

This page is **core** only (`dev.kolektiv.keel:core`). It has no Ktor
dependency. Protocol format `keel/1`. Seed version `1`.

## Releases (recommended)

Current line: `0.0.1`.

## Snapshots instead

If you are tracking `*-SNAPSHOT*` builds, swap the URL. Do not keep
releases on the classpath at the same time.

```
https://repo.yuri.capital/repository/maven-snapshots/
```

Publishers write to `keel-maven` (grouped) plus one of those two. You only
need the consumer URL you chose.
