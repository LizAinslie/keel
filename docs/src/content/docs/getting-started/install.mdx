## Maven — host

The core artifact has no Ktor dependency. `dev.kolektiv.keel:ktor` binds the
registry to routes, serves the HTML shell, and answers visits on the page URL
(`X-Keel-Visit: true`). Publish locally from this repo with the included
conventions plugin.

<CodeBlock lang="kotlin" bw="ktor" title="build.gradle.kts" code={`plugins {
    id("keel.published-library")
}

dependencies {
    implementation("dev.kolektiv.keel:core:0.0.1-SNAPSHOT.1")
    implementation("dev.kolektiv.keel:ktor:0.0.1-SNAPSHOT.1")
}`} />

Coordinates: `dev.kolektiv.keel:core`. Protocol format `keel/1`. Seed version `1`.
You ship at least one pack — your UI, or the default theme the host falls back to.

## npm — router and rig

The TypeScript workspace lives in `packages/` and is managed with pnpm. The
router is framework-agnostic. Each rig is a thin binding.

`@kolektiv/keel-pack` is the pack build: a Vite plugin that discovers `+page.svelte`
files, writes `manifest.json`, and zips a `.feb`. Point `keelPack` at your pages
directory and bootstrap; do not list entries by URL.

<CodePair
  title="vite.config.ts"
  fw="svelte"
  ts={`import { svelte } from "@sveltejs/vite-plugin-svelte"
import { keelPack } from "@kolektiv/keel-pack/vite"
import { defineConfig } from "vite"

export default defineConfig({
  plugins: [
    svelte(),
    keelPack({
      id: "app",
      version: "0.1.0",
      framework: "svelte",
      pagesDir: "src/pages",
      bootstrap: "src/bootstrap.ts",
      contract: "src/lib/page-types.ts",
      pack: "dist/app.feb",
    }),
  ],
})`}
  js={`import { svelte } from "@sveltejs/vite-plugin-svelte"
