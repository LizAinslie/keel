Svelte is the first adapter. Pick **one** npm repository: releases for
numbered versions, or snapshots for `*-SNAPSHOT*`. Do not point the scope
at both.

## Releases (recommended)

Current line: `0.0.2-SNAPSHOT.1`. Put this in `.npmrc` at the pack root (or your user
`~/.npmrc`):

```bash
# .npmrc
@kolektiv:registry=https://repo.yuri.capital/repository/npm-releases/
```

Then install:

`@kolektiv/keel` is the host router (visits, history, prefetch, `action()`).
`@kolektiv/keel-svelte` is the Svelte 5 bindings. `@kolektiv/keel-pack` is
the toolchain: `keel-scaffold` from a live host schema, a Vite plugin
(`keelPack`) that discovers pages and writes a `.feb`, and `keel-pack` to
zip a dist by hand.

## Snapshots instead

If you are tracking snapshot builds, point the scope at snapshots **instead
of** releases:

```bash
# .npmrc
@kolektiv:registry=https://repo.yuri.capital/repository/npm-snapshots/
```

Publishers write to hosted `keel-npm`. You resolve from the group you
chose (`npm-releases` or `npm-snapshots`). Resolving does not require
Nexus credentials; publishing does.
