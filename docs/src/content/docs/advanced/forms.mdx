Forms are visits. `Form` progressive-enhances a real `<form>`. `useForm` holds
field state, errors, processing, and progress. A 422 is still a seed — with
`errors` — so the page can stay put.

Typed JSON writes that are not a page go through
<a href={path("/docs/core-concepts/actions")}>server actions</a> and
<a href={path("/docs/advanced/query")}>`useAction`</a> instead.

<CodePair
  fw="react"
  title="useForm"
  ts={`const comment = useForm({ body: "" })

function onSubmit(event: FormEvent) {
  event.preventDefault()
  void comment.post("/p/hello/comments", {
    preserveScroll: true,
    onSuccess: () => comment.reset(),
  })
}`}
  js={`const comment = useForm({ body: "" })

function onSubmit(event) {
  event.preventDefault()
  void comment.post("/p/hello/comments", {
    preserveScroll: true,
    onSuccess: () => comment.reset(),
  })
}`}
/>

`preserveScroll: "errors"` restores scroll only when the seed has errors.
`preserveState` keeps the module mounted so field focus survives the round-trip.
